## 背景

短剧与课程类内容在弱网下体验很差：起播 3 秒、切集必转圈、CDN 流量成本随日活线性增长。目标是做一个能在 Web、Android WebView、微信内置浏览器里稳定跑的多端播放器，并接入 P2P 分发降低带宽成本。

## 我做了什么

- **播放内核**：在 hls.js 上自定义 loader，把分片加载与 P2P 调度解耦；P2P 不可用时自动回源，同一分片不会重复请求。
- **首屏**：预取首个分片 + 首帧解码前置，4G 中端安卓起播从 3.1s 降到 1.2s。
- **弱网**：按吞吐估算动态切码率，300kbps 仍可播放 480p；卡顿超过 2 次自动降档。
- **可观测**：播放失败按「拉流 / 解码 / 渲染」三层上报，线上问题定位从小时级压到分钟级。

```ts
const loader = new P2PLoader({ fallback: HlsLoader, tracker })
hls.config.loader = loader
```

## 结果

| 指标 | 改版前 | 改版后 |
|---|---|---|
| 起播耗时 | 3.1s | 1.2s |
| CDN 流量 | 100% | 38% |
| 播放失败率 | 1.8% | 0.6% |

上线三个月，日活 300+，崩溃率 0.02%。播放器代码私有，演示站为脱敏版本，只保留交互与数据结构。
