## 背景

用例散落在十几份 Excel 里，回归靠「上次是谁测的」；版本一发，没人说得清哪些用例覆盖了改动点。作为前端负责人，我重做了内部测试用例平台。

## 我做了什么

- **用例树**：模块 / 子模块 / 用例三级，支持批量移动、复制、导出 Markdown。
- **计划与执行**：一个计划挂一批用例，执行结果实时汇总；失败可直接生成缺陷单并回填链接。
- **版本对比**：按版本查看用例增量与失效用例，回归范围由系统给出而不是拍脑袋。
- **权限与审计**：只做两个角色（编辑 / 只读），所有改动留痕。

```sql
SELECT c.id, c.title, MAX(r.status) AS last_status
FROM cases c LEFT JOIN runs r ON r.case_id = c.id
GROUP BY c.id HAVING last_status != 'pass';
```

## 结果

- 用例沉淀 1.2 万条，30 天内被引用 4,800 次。
- 版本回归准备时间从 2 天缩短到 4 小时。
- 上线半年，新增用例的平均录入时长 38 秒（含标签与步骤）。
