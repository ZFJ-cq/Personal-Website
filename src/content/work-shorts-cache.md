## 背景

短剧用户大量在地铁、电梯里看剧，网络一断就回到列表页，重进还得重新缓冲。产品希望「看过的能离线看，正在看的能续上」。

## 我做了什么

- **边下边存**：播放时按分片落盘，落盘与播放共用一份请求，不额外耗流。
- **断点续传**：任务状态存 IndexedDB，杀进程后恢复；分片级校验，坏片自动重下。
- **空间治理**：LRU 清理 + 单剧上限，剩余空间低于 500MB 时停止预下载。
- **失败兜底**：存储不可用（隐私模式 / 配额满）时自动退回在线播放，不阻断主流程。

```ts
await cache.write(chunk, { dramaId, episode, seq })
if (!cache.hasSpace()) await cache.evictLRU(200 * MB)
```

## 结果

- 离线可播率 96.4%，弱网（< 200kbps）续播成功率从 41% 提到 88%。
- 人均缓存 3.2 集，缓存用户次留 +6.8%。
- 存储异常导致的崩溃归零。
